# Orbit Build 268 / v0.3.247 — local development update

- Peak Compressor gets a dedicated rack panel with rotary controls, gain-reduction
  needle, input/output readouts and sidechain selection.
- Mixer inserts use one bypass light and a full-width effect name. Right-click
  opens the built-in/VST3 choices directly; selecting a new effect on an occupied
  row replaces that slot with Undo support.
- Playlist pattern changes stop at A1/H8. Bottom selector strips open all pattern
  slots, including blank patterns.

The compressor DSP is unchanged. Tube Distortion and Two-Band Distortion remain
available from Build 267 under Insert > FX Distortion. No new ABL emulation is
claimed. This is a local development build; no public release was published.
